# 轻养 · 健康 H5

面向移动端的健康应用框架，包含今日健康看板、饮食拍照记录、训练打卡与提醒、附近餐饮、积分、情绪陪伴和活动预约。电脑端提供侧栏布局及独立健康数据大屏。

## 本地运行

需要 Node.js 22+。依赖版本固定在 package-lock.json。

```sh
npm ci
npm run dev
```

打开 http://127.0.0.1:3001 。根路径自动进入今日看板。

```sh
npm test
npm run typecheck
npm run build
npm run test:e2e
```

浏览器测试默认使用本机 Google Chrome；如未安装，可在 playwright.config.ts 移除 channel 并运行 `npx playwright install chromium`。

## 入口

| 路径 | 页面 |
| --- | --- |
| /dashboard | 每日健康日记、饮水、体重、营养概览 |
| /nutrition | 饮食日记、照片预览与模拟识别、餐厅筛选与收藏 |
| /training | 课程、训练计时、打卡、提醒设置 |
| /companion | 预设陪伴回复、情绪记录 |
| /profile | 健康档案、积分任务与流水、兑换演示、预约活动 |
| /overview | 独立可视化大屏，支持近 7 / 30 天范围 |

## 演示范围

- 图片只在浏览器本地读取，不上传；识别返回固定示例，确认前可修改名称、份量与热量。
- 餐厅、距离、评分、活动、成员均为示例，不调用地图和商家服务，不产生真实预约。
- 聊天使用预设回复，不调用真实模型，不提供心理诊断或医疗建议。
- 提醒设置会保存，但不会发出系统通知；课程只有计时和打卡，不含视频、动作检测或实时监督。
- 积分和兑换为本地演示，无真实商品履约。
- 记录保存在当前浏览器 localStorage（键 `qingyang-health-v1`），不跨设备同步。清除浏览器网站数据会移除记录。
- 以上海日期组织记录，首次提供近七天种子数据。营养数据与热量为演示估算。
- 应用名、头像和插画均可替换；当前暂名「轻养」。

真实服务接入位置见 [接入说明](docs/service-integration.md)，设计及计划见 docs/superpowers/。
