### 用户账号表 `users` · 负责人M01

唯一账号主体；其他所有模块引用同一个用户ID。

| 字段标识（代码使用） | 中文含义与用途 | 类型与空值规则 |
| --- | --- | --- |
| `id` | 全项目唯一的用户账号 ID，由应用生成 UUID，供各业务模块引用。 | 定长文本，36个字符；数据库非空 |
| `phone_ciphertext` | 手机号密文，用于需要恢复手机号的受控业务流程。 | 长文本；数据库非空 |
| `phone_lookup_hash` | 带服务端密钥的手机号 HMAC 摘要，用于登录匹配及手机号唯一性判断。 | 定长文本，64个字符；数据库非空 |
| `nickname` | 用户昵称，由账号模块统一维护。 | 文本，最多30个字符；数据库非空 |
| `avatar_asset_id` | 头像素材 ID，关联 media_assets；未设置头像时可为空。 | 定长文本，36个字符；数据库允许空值 |
| `timezone` | 业务时区，本基线固定为 Asia/Shanghai，用于本地日期与时间换算。 | 文本，最多64个字符；数据库非空 |
| `status` | 账号状态：active 正常，disabled 已停用，deleted 已删除。 | 文本，最多16个字符；数据库非空 |
| `deleted_at` | 账号软删除时间（UTC，毫秒）；仅 deleted 状态时有值。 | 日期时间，3位小数秒，统一UTC；数据库允许空值 |
| `created_at` | 记录创建时间（UTC，精确到毫秒）。 | 日期时间，3位小数秒，统一UTC；数据库非空 |
| `updated_at` | 记录最后更新时间（UTC，精确到毫秒），记录更新时由数据库维护。 | 日期时间，3位小数秒，统一UTC；数据库非空 |
