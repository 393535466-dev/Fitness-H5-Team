# M04 正式课程素材补齐清单

本轮已按用户确认先做页面。下表尚未填入的内容保持待补，不使用预览课程冒充正式课程，不自动生成动作教学。

| 内容 | 需要提供的信息 | 当前承载方式 |
| --- | --- | --- |
| 课程身份 | 名称、分类、难度、目标人群 | 既有 CourseDto 字段；目标人群可写入 description |
| 课程介绍 | 本课目标、训练内容、适用条件与不适用条件 | 经审核后写入 description |
| 准备清单 | 场地、器械、预计准备时间 | 可暂写入 description；独立字段需契约评审 |
| 动作教学 | 动作名称、关键要点、常见问题、可用替代方法 | 正式专业内容审核后供给；本期无独立动作库 |
| 时长与消耗 | 预计时长、热量估算及其依据 | 现有字段；不把估算表述为实测 |
| 封面/视频 | 文件或资源地址、来源、使用许可、有效期 | 交 M01 媒体服务校验和授权，随后返回 coverUrl/videoUrl |
| 发布责任 | 内容负责人、审核人、更新时间、可发布状态 | 既有后台课程版本与发布流程；不把草稿直接发布 |
| 计划说明 | 模板名称、说明、逐日课程与休息安排 | 既有模板；不把“7天日程”说成“每周练7天” |

## 单节课程填写模板

- 课程名称：待补
- 分类 / 难度：待补
- 适用人群与条件：待补
- 课程目标与内容：待补
- 场地与器械准备：待补
- 关键动作要点与注意事项：待补
- 预计活动时长 / 估算热量及依据：待补
- 视频 / 封面及使用许可：待补（视频可选，无视频保留文字说明）
- 内容提供与审核负责人：待补
- 审核后是否可发布：待确认

本清单记录待补内容，不构成正式训练处方。收到素材后，应先整理和审核再写入课程内容，不需要重新设计整套页面。
